# EP143 播客对话稿：何小鹏——物理AI的豪赌

H: 大家好，欢迎收听本期节目。今天我们要聊的嘉宾，去年说过一句话让我印象特别深——他说造车就像在血海里游泳。他就是小鹏汽车的董事长兼CEO，何小鹏。

G: 大家好，又见面了。不过今年我想说的可能不只是血海了，因为我们现在还跳进了另一片海，一片更深的、更冷的海。

H: 对，过去一年小鹏的变化其实特别大。你们把公司名都从"小鹏汽车"改成了"小鹏集团"，定位也从AI汽车企业变成了物理AI企业。我特别好奇，这个转变到底是怎么发生的？

G: 其实这个转变不是一夜之间发生的。过去十年我们做的核心就是六个字——智能电动汽车。但去年我们突然意识到，用软件的方法加AI的工具，做出来的东西本质上还是一个缝合怪。它不是真正的AI驱动。

H: 等等，你先别急着往下说。我想先做个小调研，你平时自己用AI产品多吗？

G: 说实话真不多。我还是在用很传统的AI产品，千问、豆包这些。团队内部编程工具用得非常多，但我自己不太愿意深度用。

H: 为什么？你自己就是做AI的。

G: 因为我发现一旦你天天用产品，你很快就会陷入细节。你会盯着哪里不好用、哪里有问题，然后聚焦怎么去解决。但你反而不能向远方看了。做一号位，要用，但不能太深度地用。

H: 你说的这个"缝合怪"特别形象。能不能具体说说，你们之前那套体系到底哪里不对？

G: 我们之前同时在做两代自动驾驶系统。第一代是在原来端到端的框架上把模型放大、把规则减少。但第二代我们换了个思路，用更大的基础模型，先打开上限再去收下限。然后我们做了一个巨大的赌注——把第一代整个停掉了。

H: 等等，停掉？那套体系花了多少钱？

G: 小几十个亿吧。从业务到技术甚至到组织，全部停。去年大概就是这个时间段做的决定。

H: 这太狠了。你内部没有反对声音吗？

G: 肯定有。大部分非AI方向的主管觉得不管做A还是做B可能都是错的。跟AI相关的主管里，有人觉得对，有人觉得不行，大部分人在中间观望。但我觉得这就是创业的乐趣，你就是在赌十倍到一千倍的可能性。

H: 你刚才说用软件的方法做AI是缝合怪，那你们现在走的路到底是什么？为什么叫物理AI？

G: 数字AI用的是人类的语言，语言是高度概括和浓缩的。但物理世界不是。你每天看到的数据量，根本没法用语言去描述和还原。所以物理AI的数据、模型、方法论跟数字AI完全不一样。它难一百倍。

H: 那你觉得现在行业里对物理AI的理解到位了吗？

G: 远远不够。很多人拿数字AI的逻辑去套物理AI，我觉得那是在用二维的尺子量三维的东西。数字世界看长板就够了，物理世界你得长板、短板、窄板全都顾到。窄板要做宽，短板要做长，长板要更长。

H: 所以你说物理世界的CEO不敢赌？

G: 对，物理世界的CEO要么不敢赌，要么觉得我还有好多块板怎么办。我可能胆子比较大。我也不知道短板能不能解、窄板能不能变宽，但我们还是下了这个赌注。

H: 说到赌，你之前还提过一个观点让我很意外——你说你不怎么控制公司内部的token用量。这在现在大家都在精打细算算token成本的环境下挺少见的。

G: 我们确实不太看token这个指标。很多人说一个季度就把一年的费用烧完了，但我觉得如果他真能做到，那反而说明他产生了价值。我最多管一下最异常的top ten的情况，其他的都开放。

H: 那你们现在算力怎么分配？主要给谁用？

G: 主要还是自动驾驶和座舱合并之后的大团队。但我们内部其实不太用token来衡量，我们算的是给你三万张H100、五万张H100，你能跑什么业务、效率怎么样。token更像是应用层公司的指标。

H: 你刚才提到数据成本特别高，能展开说说吗？

G: 数字AI领域几十个TB就够训练了，我们一次训练就是几十到几百个TB。光是数据的存储、管理、使用，一年刚性成本就接近十个亿以上。哪些数据有价值、哪些是临时的、哪些可以快速用、哪些可以热温冷分层，每一个环节省下来的都是千万级的。

H: 那AI编程对你们这种物理AI企业意义大吗？

G: 对初级程序员来说是个很好的辅助工具，也许两三年后能逼着初级程序员都升到高级。但对智能驾驶这种强AI能力来说，帮助很小。你写个操作系统，核心是底层的方法论，不是AI编程工具。

H: 那如果把你训练成一个"何小鹏技能包"，你觉得应该喂什么数据？

G: 这个问题我们真的深度思考过。数字模型和物理模型今天还是让基础白领和基础蓝领比较容易技能化。如果连我都能被清晰地技能化，那意味着更高端的蓝白领都有巨大风险。CEO也许过数十年或者一百年确实可以被替代。

H: 那你怕吗？

G: 不怕。因为那个时候每个CEO也都会有更强的综合能力。他可能丢掉了ABC，但获得了新的DEF。关键是你是在构建体系，还是在使用别人构建好的体系，这是两个完全不同的角度。

H: 好，那我们聊聊机器人。去年你们那个机器人突然在网上爆了，完全出乎意料吧？

G: 完全没想到。那款机器人其实是我们前年一季度就开始做的一个中间版本，对我们来说只是个里程碑。结果突然全网讨论，我们团队内部还纠结要不要回应，说清者自清。我等了几小时就受不了了，我说子弹飞得太快了，必须马上说。

H: 然后你们就剪开了腿给大家看？

G: 对，剪的左腿。因为从左往右走，左腿最容易看到。我们内部知道那绝对不是人躲在里面，但全世界百分之九十九点九九的人没法亲手摸到它。所以必须用最直观的方式证明。

H: 那次舆论风波给你们带来了什么信号？

G: 特别有意思。年轻人大部分希望机器人进家庭帮忙干活。但我认识的那些不发朋友圈的中年人，他们想的是等老了以后机器人能干什么。这两种视角完全不一样，以前没有这么大的数据量让我们看到这种差异。

H: 你们为什么一定要做通用人形机器人？这条路不是最难吗？

G: 我们选了一个最像人的形态。我觉得机器人如果要真正走进人类社会，对基础蓝领和白领都产生价值，它一定要走到我们身边。你想想一个一米八、全身盔甲的机器人站在你旁边，你自己都会觉得有压迫感。老人和小孩怎么办？安全法规怎么解决？

H: 那你们现在这一代机器人多高？

G: 大概一米六九到一米七零，男女生都比较舒适的身高。它可以穿衣服、有头发，但不能有自己的脸。一个是恐怖谷效应，还有法律和社会学上的考量。

H: 你说机器人创业的难度是造车的二十到一百倍，这个判断是怎么来的？

G: 汽车造出来，假设没有竞品、有用户需要，你基本能卖出去。但机器人到今天还没有被定义清楚。市场在等一个类似iPhone 4的时刻。而且汽车有道路、有法规、有量产爬坡，机器人一旦规模化，速度会远超汽车，但前面的坑也深得多。

H: 那你觉得自己的胜率有多大？

G: 大概两成吧。这已经是我看到的中国企业里最高的了。

H: 两成你还敢赌？

G: 创业不就是在你当时的能力上赌十倍到一千倍的可能性吗？规模大了之后你不能赌一千倍了，但数倍到十倍之间你还是要赌。越犹豫、越等待、越观察，你越难成功。

H: 去年你们内部组织架构也做了大调整，能说说吗？

G: 三季度末我们把整个自动驾驶中心的核心组织架构全改了。每个人都有原来的惯性，习惯用过去的方法加最新的工具。但很多时候你的工作方法论本身就得换。不能小刀砍大树，想清楚了就从组织到流程到方向全部改。

H: 你花最多时间的事情是什么？

G: 不是车，不是机器人，不是AI，也不是采购。是战略和规划。未来是什么样的，这个问题需要技术、组织、市场所有能力的组合才能回答。

H: 你焦虑吗？

G: 当然焦虑。你会发现你以前的很多逻辑，甚至逻辑底下的定理、范式，再往下的公理层——你的价值观、人生观、世界观——在这些变化下好像不那么work了。看到问题、解决问题、构建体系，这是三种完全不同的能力。

H: 今年你们还要发新车GX，这是一款什么样的车？

G: 这是我们第一次做全尺寸六座大SUV，旗舰定位。今年北京车展大概有三十款这样的车，我们想做的是把汽车、飞行汽车和机器人的能力在这一代车里贯通起来。

H: 具体怎么贯通？

G: 比如我们把飞行汽车的飞行核心零部件冗余带进来了，全车八个安全冗余。电源坏了能开，动力坏了能开，线束被咬坏了还能开。就像飞机一样允许你有冗余。我们还把线控底盘跟新的电子电气架构跟自动驾驶关联起来，安全级别更高、时延更短。

H: 担不担心重蹈G9的覆辙？

G: 不担心。那个时候的思考逻辑跟现在差别非常大。当你的体系能力到了更高的维度，你大概率能分析出以前的问题在哪，也能看到现在的问题在哪。这已经是完全不一样的能力级了。

H: 你怎么看跟理想的竞争？

G: 我们跟每一家都是友商，也是同盟者，也可能是竞争者。我昨天还去李想展台看了新一代L9，也去李斌那看了ES9。我相信蔚小理在大六座这个赛道上会给出各自不同的认知。

H: 你之前说造车像血海游泳，那现在游出来了吗？

G: 都在游，我不觉得有谁出来了。在我的定义里，没有一家游出来。三十年后中国可能就五家有规模的车企，不代表其他的会倒闭，但规模下行会导致越来越难进入超高强度的竞争。

H: 那机器人的血海呢？

G: 机器人现在还没进血海，血还在前面。但机器人的血海会像当年互联网竞争一样，很快从血海变南海。因为机器人里AI占的能力很强，而原来在血海里一起游泳的人大部分不太懂AI。同质化内卷的可能性会低一些。

H: 最后一个问题，过去有没有什么后悔的决策？

G: 没有。这个世界上不需要去思考后悔的决策，因为犯错的太多了。犯错为什么要后悔呢？我们会一起思考为什么现在错了，但不用后悔。

H: 好，感谢何小鹏今天跟我们分享这么多。从血海到物理AI，从机器人到新车，能看到一个创业者在技术剧变时代的焦虑、赌注和坚持。

G: 谢谢大家。我觉得2027、2028年开始，大家会看到物理AI出现类似数字AI那种巨大的变化。我们一起期待。
