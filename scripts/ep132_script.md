# EP132 播客对话稿：新海图创始人高继阳

H: 大家好，欢迎收听本期节目。今天我们聊一个很有意思的人，新海图创始人高继阳。在具身智能这个赛道里，大家都在讲大脑、讲模型，但他偏偏说，我得先把机器人造出来。

G: 对，我是高继阳，九二年的，河北石家庄人。很多人第一次见我都觉得我像八零后，可能创业确实让人老得快吧。

H: 我特别好奇你的成长轨迹。你从小就是那种学霸吗？

G: 真不是。小学成绩还行，班级前十的样子，但绝对不算拔尖。六年级暑假我第一次真正用功，为了考重点班的分班考试，结果考了年级第三。那是我考试生涯里第一次尝到甜头。

H: 后来高中走了物理竞赛这条路，保送上了清华。你觉得那是天赋还是勤奋？

G: 我见过真正有天赋的人，人家做一遍就会了，我搞不明白。我的办法就是归纳总结，把不同题型映射到考点，别人刷一遍我刷四遍。最后拿了全国二等奖，正好那年清华让二等奖调专业，我就去了电子系。

H: 你说自己不是天才，那你觉得自己最核心的能力是什么？

G: 归纳总结。从物理竞赛开始我就靠这个，把不同题型映射到考点，形成一套方法论。后来发论文、做工程、创业，底层都是这个。我考试也好，做事也好，核心就是拆解、归纳、然后找规律。

H: 在清华你见到了杨植麟，他跟你一届。他是什么感觉？

G: 高不可攀的大神。清华里大神太多了，我们班有个同学，我抄他作业都看不太懂，得换一个人的参考。上了清华最大的收获就是学会了谦虚，天外有天，人外有人。

H: 你大学期间就确定要创业了？

G: 大二大三的时候就想好了。但那时候最火的是移动互联网，王兴、张一鸣那一波。我觉得跟我没关系，我太年轻了，啥也不懂。一代人有一代人的机会，人家积累了那么多年，轮到他们了。我得找属于我的机会。

H: 但你后来申请博士不太顺利，这件事对你影响很大？

G: 是个小打击。当时我就开始反思，看了很多书，尤其是曾国藩的传记。他二十多岁是个儒家清流，四十岁变成了一个特别会带团队、拿结果的人。他的顿悟是，做一件事最重要的不是清高，而是你能拉动多少资源把事做成。

H: 这个感悟对你触动很大？

G: 非常大。我申请学校走不通，就相当于儒家清流做不了了。那我就得从底层思考我未来要做什么、要为这件事做什么准备。从那之后我系统性地看了各种方向，不再把表面的东西当目标。

H: 这个转变怎么把你引向了人工智能？

G: 大四的时候汤晓鸥老师在学校有个小范围交流，我第一次知道了深度学习。他给了我一个实习机会，我啥也不会，连神经网络都没碰过。结果一去训练了第一个模型，我就发现，天哪，计算机可以自己从数据里提炼规律，不用人写规则了。那天我骑着自行车从清华科技园出来，脑子里就一个念头，我以后必须做这个。

H: 这个瞬间太关键了。后来你去美国读博，三年半就毕业了，怎么做到的？

G: 我给自己定了个目标，正常五六年，我四年。然后倒推时间表，第一年就要投顶会。我发现发论文也有套路，无非三种，挖坑型的、提性能的、降成本的。我把想法分给同学一起做，提高效率。到第三年攒够了，就提前毕业了。

H: 博士毕业你面临选行业，最后为什么锁定了自动驾驶？

G: 我给自己定了个标准，人工智能必须是这个行业最底层的变量，没它这行业就不成立。广告没有它也能做，云计算没有它也能做，但自动驾驶不行。而且我把它延展了一下，自动驾驶其实是物理世界智能的第一个形态，未来是人工智能加机器人。

H: 第一站你去了谷歌旗下的自动驾驶公司。你进去之后发现什么问题？

G: 两个感受。第一是大公司病，我们还没做出价值呢，团队就从十个人膨胀到七八十人，一切跟母公司对齐。第二更本质，它没有创始人。自上而下的力量是缺失的，不像马斯克，说干啥哪怕错的也能立刻干。

H: 你觉得它和特斯拉的根本区别是什么？

G: 底层逻辑不一样。它用的是机器人学的方法论，拆模块、处理边界情况，感知里有几十个模型。特斯拉是人工智能原生的，追求端到端、数据驱动。零八年和十八年的技术架构其实没变，只是把小模块里的算法换成了神经网络。

H: 在那两年你最大的收获是什么？

G: 工程师思维定型了。就是拆解加测量，把复杂问题拆成子问题，拆到最后就是一行行代码，测量到最后就是一个个单元测试，再一层层回去看指标。这套方法论后来在创业里反复用到。

H: 然后你回国加入了量产自动驾驶公司。为什么选它？

G: 我想做量产，想做产品，离客户更近。它的创始人战略能力极强，十八年就判断要走量产路线，通过数据飞轮走向无人出租车。而且它够强势，一个组织必须有人能说我们错了然后改，这太重要了。

H: 那段经历最核心的学习是什么？

G: 学会了什么叫以客户为中心。不是客户说啥就干啥，而是真正站在客户角度挖掘需求，提出更好的方案。而且这个理念不只是对外的，公司内部上游对下游也是客户关系。跟这个相对的，以自我成长为中心、以技术领先性为中心，对做企业来说都是错的。

H: 你离开的时候放弃了大概一千万美金的期权，心疼吗？

G: 一点都没有。跟我想做的事比起来，那些东西价值不大。而且日常我也花不了多少钱，吃饭够了，再多再少也没什么区别。

H: 是什么让你觉得时机到了？

G: 二十二年底，大语言模型让世界再一次相信了人工智能，这很重要。同时量产自动驾驶让端侧智能成为可能，机器人用的传感器和算力跟自动驾驶大差不差。加上特斯拉正式宣布做人形机器人，我觉得要素都齐了。

H: 创业第一件事你为什么死磕整机？你们一个软件团队，完全可以先做大脑啊。

G: 因为长期壁垒建立在物理世界的数据闭环上，没有硬件载体就没有数据。中短期我们的商品也不是一个算法，而是整机加智能形成的、能在物理世界执行的实体。两件事都倒推回来，我必须把整机做好。

H: 但你们一个软件团队，做硬件不是从零开始吗？

G: 真的是从零开始。早期拆别人的产品，连工具都没有。后来一个结构负责人来公司看我们太可怜了，送了我们一箱改锥锤子镊子。淘宝以图搜图找供应商，完全不知道那些零件叫什么。起点非常非常低。

H: 后来怎么解决的？

G: 遇到了泽一，九七年的，我认为是天才。他第一次给我有框架性地讲清楚了整机系统是怎么回事，又有洞察力，能说出个一二三。我去了两次深圳，第二次就邀请他加入。现在公司所有产品的大框架设计都是他把关。

H: 最早你们想做配送机器人，后来为什么变了？

G: 二十四年三月，整机刚开始做，我就发现不工作。整机不成熟，供应链没有，智能没准备好，客户也不成熟。我们马上调战略，做轮式加双臂，聚焦操作，切入开发者市场。运气不错，歪打正着。

H: 开发者市场这个概念怎么理解？

G: 它不只是卖高校。我们把它看成金字塔，塔尖是学术型开发者，往下是企业内的研究型开发者，再往下是生产力型开发者、集成商，最后是终端用户。这其实就是科技产品从创新者走向早期大众的标准路径，苹果个人电脑、拓竹打印机都是这么走过来的。

H: 为什么不做双足人形？

G: 双足运动控制和双臂智能操作同时要解决，这个问题到今天也没人解决。我们得先解耦，先把上肢操作做好。而且很多真实场景不需要过坎走路，轮式足够了。我们叫智能定义本体，从智能的需求出发决定本体怎么做。

H: 在数据策略上你们非常坚持用真实数据，为什么？

G: 这是从自动驾驶里学到的教训。九十九点九的问题还是靠路测数据解决的。而且有个底层原理，你要解决的问题在哪个领域，训练数据最好也在那个领域，不然就有领域迁移的问题。仿真数据的视觉差距太大了，很难克服。

H: 真实数据到底多贵？你算过账吗？

G: 算过。获取一小时的真实操作数据，实际要投入三到四小时的人工，加上机器人折旧，大概两百到两百五十块。十万小时的数据成本两千五百万，而十万小时正好是一个人从出生到十八岁跟物理世界交互的总时长。这么算其实不贵。

H: 但仿真数据获取成本低得多啊，为什么不全用仿真？

G: 得算总账。数据获取成本和训练成本的比例大概是一比五到一比十。如果数据质量低，你把大量钱浪费在训练环节了。所以贵和便宜不能只看获取那一步，要看智能的总成本。

H: 你们的大脑架构是视觉语言动作模型加多模态语言模型的双系统，为什么不做一个端到端？

G: 端侧算力是有限的，你不可能把几十甚至上百参数的推理模型放在机器人上。执行动作的模型必须在端侧，不然延迟解决不了。而且很多工商业场景就二三十个动作，直接调用动作模型的语言接口就够了。真正需要语言模型推理的，是家庭这种更通用的场景。

H: 面对大公司，你们的优势在哪？

G: 得反过来看，大公司相比我们有什么优势。它们有算力、有人才、有基础设施，但最缺的是数据。而数据这件事，需要懂模型的公司来定义数据体系和治理体系，否则采来的全是垃圾。我们有整机、有模型认知，这是做好数据的前提。

H: 最近你们的联合创始人许华哲要离开了，这是路线分歧吗？

G: 华哲是非常有影响力的科学家，我们对他的前沿判断力非常认可。分歧在于，我们到底是一步步围绕客户价值务实创新，还是更多做超前探索。最后我们决定支持他去创业做家庭应用方向，新海图也会投资他的公司。这是实事求是的选择。

H: 这是不是说明算法创新在现阶段没那么重要？

G: 绝对不是。我们的算法创新能力非常强。但算法不能独立于基础设施存在。你看整个价值链条，整机供应链的传播周期是十二到十八个月，客户渠道六个月起步，数据体系再加六到十二个月，而算法的传播周期只有两到三个月。它投入大，但壁垒最小。

H: 所以你们的价值观叫务实创新？

G: 对，先务实再创新。我是理想主义的人，但理想主义不能变成空想。理想主义能实现的基础，是每天都要算投入产出比，算每件事对长期战略和短期收益的贡献。创业公司先生存，再谈别的。

H: 你之前说机器人行业没有技术浪漫主义的人，为什么？

G: 因为这个行业链条太长了。做语言模型不用操心供应链、不用操心数据、不用跟线下客户打交道，安安静静做研发、做传播就行。我们天然就得把头伸到土里去，土一点，就没法浪漫。这个行业会把人塑造成不一样的状态。

H: 如果给听众推荐一本书，你推荐什么？

G: 我最近在看吕思勉讲三国的那本。三国的状态跟具身智能今天很像，没有谁是草帽，也没有谁是绝对的理想主义英雄，都是在现实中挣扎、取舍，凭一些运气取得胜利，然后步步为营。好在今天不是你死我活，每个公司都可以很好。

H: 最后一个问题，你觉得新海图像什么动物？

G: 第一反应是狼，但我觉得又不太准确，因为现在哪家公司不狼性。可能最接近的就是狼吧。我们不是靠一个极端选择取胜，而是步步为营。二十四年搞整机供应链，二十五年搞数据和智能，二十六年做场景和应用。长期战略我非常坚持，但不会在一个时间段把所有事同步展开。

H: 非常感谢继阳今天的分享。从物理竞赛到清华，从自动驾驶到具身智能，你一直在做一件事，就是把复杂问题拆解、测量、然后拿到结果。这期节目就到这里，我们下期再见。

G: 谢谢大家。我想说的是，视频里呈现的机器人状态比现实中好得多，大家还是要给这个行业更多耐心。但这件事一定会发生。
