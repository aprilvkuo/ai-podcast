# EP118 播客对话稿：李想谈AI、智驾与人的智慧

H: 大家好，欢迎收听本期节目。今天我们拿到了理想汽车创始人李想将近三个小时的深度访谈完整版，信息量巨大，浓缩成十五分钟，带大家抓住最核心的观点。

G: 这次访谈形式特别有意思。主持人把李想当成一个大模型来提问，说他是混合专家架构。前三个回合调用了技术专家、战略专家和组织专家，后半程完全转向人的能量、亲密关系和人类智慧。

H: 先从最扎心的问题开始。李想说过去一百三十天，AI发展这么好，但他每天工作时间并没有减少，反而还在增加。身边所有人都在说AI好，但工作成果并没有实质性改善。

G: 他看到了中国AI的巨大进步。DeepSeek、千问这些模型，让中国在基座模型、推理模型和多模态上跟美国基本拉平了。而且中国企业做出来的模型效率更高，无论训练还是推理层面都做了很多深层工程改造。

H: 但他也看到了一个严重问题。大部分人用AI还是当信息工具，先点个联网搜索，通过检索增强生成做索引。但索引的信息源本身就不准确，推理过程再认真，结果也已经开始有问题了。

G: 他说某种程度上这是在熵增，增加大量无效信息、无效结果、无效结论。DeepSeek刚出来的时候，很多人把推理过程截图发小红书，大家还爱看。现在没人发了，也没人看了，因为千篇一律。

H: 所以他提出了一个清晰的三级分类：信息工具、辅助工具和生产工具。信息工具你并不愿意付钱，辅助工具你觉得是产品应该自带的。只有生产工具，你才真正愿意为它付费。

G: 他问身边同事，真正算得上初级生产工具的只有两个：Cursor和OpenAI的Deep Research。Cursor是编程同事在用，Deep Research是商分和战略团队在用，而且都是员工自己掏钱买的，没花公司的钱。

H: 为什么到今天还没有真正的生产工具？李想说核心就两个字：行动。你用再聪明的模型，它只是给你策略和推演，但你工作还是要自己操作电脑。必须得有行动，行动才能产生价值。

G: 他特别强调知行合一。今天你用多么聪明的推理模型，它并没有真正去行动，只是给出策略。像Manus已经开始做行动了，自动驾驶也是控制一个机器在物理世界行动，这才能产生价值。

H: 他举了个特别生动的例子。你比我聪明十倍，但你拿勺挖坑，我拿铲子挖，我效率都比你高。更好的大脑和使用更好的工具完全不冲突。脑子变强以后工具可以变得更强，工具意味着更高的确定性和更低的能量消耗。

G: 他特别肯定了Manus，说它是往生产工具走的最大一步。比如分析特斯拉股票，它会去浏览证监会网站，去读各大投行分析师的原始报告，而不是简单用检索增强做信息索引。这更像真正的专业工作人员要做的事。

H: 但Manus的挑战是通用智能体覆盖面太广了。为什么这样的产品可能是创业公司做出来的？他说大公司分工太精细，模型团队只想做好模型解决一切问题，但好产品往往是多个东西的组合。

G: 这就引出李想一个核心判断：五年之内不会有通用智能体，但会有一个智能体操作系统。各专业领域的人在上面开发自己的专业智能体，就像不同工种共同享用一个操作系统。

H: 他类比说DeepSeek开源更像Linux推出，理想要做的是基于语言基座构建交通领域的安卓。他明确说理想做的智能体操作系统只有司机这一个。教育应该是猿辅导好未来去做，我们不专业不碰。

G: 他说公司内部也需要很多智能体，客服、编程、销售、验证实验都应该由各专业团队自己做。智能商业团队可以把公司内部的智能体操作系统做出来，让每个专业在上面放自己的数据、语料和思维链。

H: 好，聊重头戏，VLA司机大模型。李想说智能驾驶经历了三个阶段。第一阶段规则算法，像昆虫智能，靠既定规则和高清地图，脑子只有几百万参数，几乎做成了有轨交通。

G: 第二阶段端到端，像哺乳动物智能。马戏团动物跟人学骑自行车，看到三维图像和速度给出轨迹。大部分泛化没问题，但遇到没学过的复杂场景就懵了。配了视觉语言模型做辅助，但开源模型在交通上能力非常有限。

H: 第三阶段VLA，完全像人类司机。它能用三维视觉和高清二维视觉看物理世界，能看懂导航地图，有语言部分和推理能力，还能像人一样执行行动。他说VLA不是突变，是进化的过程。

G: 如果用用户语言讲，VLA就是司机大模型。它像人类司机一样理解物理世界，像人类司机一样开车处理复杂问题，也能像人类司机一样跟人沟通。这是最后交付给用户的产品的本质。

H: VLA怎么训练？他讲得特别细，分三步。第一步预训练，训一个三十二B的云端视觉加语言基座。数据跟普通语言模型不同，要放三维视觉、高清二维视觉、驾驶语料和视觉语言联合语料。

G: 他特别强调高清二维视觉。今天开源多模态模型的二维清晰度太低，看的距离不够。他们放的距离提升了三到五倍。还有导航地图和车辆判断的联合语料，这些都是理想自己的原始数据，别人没有。

H: 预训练完要蒸馏成三十二亿的端侧模型，八个专家组成的混合专家架构。直接跑完整模型，双Orin X和索尔U的帧率达不到，所以必须蒸馏。但云端三十二亿后面还要继续用，不是蒸馏完就不用了。

G: 第二步后训练，相当于去驾校学开车。把行动放进来做成端到端，规模从三十二亿扩到大概四十亿。思维链控制在两到三步，不能再长，否则延时满足不了交通安全。

H: 做完行动之后还会做一个扩散预测，预测未来四到八秒的轨迹和环境。这部分会根据性能决定。他说这一步特别像人在驾校认真学开车，是从视觉到理解再到输出的完整链路。

G: 第三步强化训练，相当于上社会开车。分两部分：第一部分人类反馈强化学习，用接管数据做安全对齐，让车遵守交通规则、融入社会驾驶习惯，不能像新手给人添堵。

H: 第二部分纯强化学习，用世界模型生成数据。只给三个反馈：舒适性用G值衡量、碰撞事故、交通规则。从A到B又舒适又合规又不撞，就越开越好。这三步跟人非常像：先学知识，再上驾校，再上社会。

G: 有个数据特别惊人。过去人类司机做一万公里验证，成本十七到十八万。现在用世界模型只要四千多块钱，基本都是算力成本。而且效率提升巨大，世界模型可以百分之百还原真实场景。

H: 他举了端到端解决不了但VLA能解决的例子。路上遇到复杂修路，规则算法可能直接撞上，端到端能停下来但犹犹豫豫不知道怎么办。VLA有理解能力轻松处理，还能生成数据训练，三天之内相关场景都能搞定。

G: 还有公交车道的例子。最右边公交车道标线不清楚了，端到端老往那条道跑，纠正了过一阵又跑回去。有了VLA和智能体之后，你用自然语言说“接下来在中间车道行驶”，它就能理解执行。

H: 他说短指令可以直接在车端处理，复杂长指令会先到云端三十二亿模型，理解完再交给车端VLA执行。最后的好处就是它能像人一样理解物理世界，也能像人一样跟人沟通。

G: 为什么交通是VLA最好的实验场？三个原因。第一规则清晰，车不能开到水里也不能开到空中，复杂但确定。第二车只有三个自由度，模仿学习特别容易，不像机器人上来就四十个自由度。

H: 第三强化学习指标特别清晰。舒适用G值表达，合规有交通规则，是否碰撞可以表达。三个条件都满足就越来越好。所以交通是VLA最早实现的领域。他打了个趣：刚开始大家都要做AI造人，我们其实是在造司机。

G: 安全怎么解决？他们成立了一百多人的超级对齐团队。他打比方：模型能力是专业能力，超级对齐是职业性。我不可能雇职业赛车手每天给我开车，我要雇职业司机，保证舒适安全，价值观跟人类对齐。

H: 他说模型能力越强越需要职业性约束。就像一个人能力越强，干好事很强干坏事也很强。公司规模越大越需要职业性。伊利亚当年想的那么远，就是因为模型能力强的时候才发现对齐的重要性。

G: 那VLA是终极架构吗？他说VLA能解决到全自动驾驶，但是否效率最高他打问号。因为底层还是Transformer，这个架构是否效率最高不好说，但它是现阶段能力最强的架构，跟人类差距最小，甚至有机会超过人类。

H: 他还强调不能放弃工具。团队太想用模型解决一切，但ETC的例子说明问题。视觉语言模型对位置判断很糟糕，十几个ETC口就混乱了。他让团队用规则算法，一周不到就解决了，过去三四个月都搞不定。

G: 这个例子特别能说明他的工程观。就像乘法口诀，它也是规则算法，但消耗脑力更少、准确性更高。确定性强的问题用规则，意味着更低算力消耗和更高准确性。更好的大脑和更好的工具并不冲突。

H: 聊DeepSeek的影响。李想说DeepSeek帮他们缩短了大概九个月，省了大几亿。他春节之前就做了决定，基于DeepSeek开源做VLA的语言部分。他说本来不敢跟模型团队聊，怕大家有心理障碍。

G: 先跟谢炎聊，谢炎说肯定应该这么做。后来发现团队拥抱得特别快。陈伟比他还坚决，说应该以DeepSeek为基础加速推进。他说DeepSeek开源程度接近Linux，比安卓开放得多。这纯粹是感谢DeepSeek，是情怀不是战略。

H: 那为什么还自己做基座？业务需要。车上有对话和多模态，自动驾驶需要三维视觉和高清二维视觉的token，还有交通和家庭用户的专业语料。这些DeepSeek和OpenAI都没有，只能自己做。只是语言部分可以站在巨人肩膀上。

G: 训练卡比预期多买了三倍。给理想同学用三千亿模型，给自动驾驶用三十二亿模型。但没什么捷径，没办法直接摘第十个包子。如果规则算法都做不好，根本不知道怎么做端到端。前面每个包子都跳不过去。

H: 他从DeepSeek学到了人类最佳实践。V3背后是极简四步法：先搞研究，再搞研发，然后表达能力，最后变成业务价值。R1的推理也是四步：索引分析、确定目标、涌出策略、反思复盘。

G: 他说这就是人类做业务的最佳实践，但人类经常做着做着就忘了。大家遇到问题只想改策略，不做复盘不做分析。严格按最佳实践是反人性的，随心所欲才满足人性。卓越的组织和个人，很多时候要跟人性做对抗。

H: 他聊了梁文峰。去年九月见过一次，印象最深两点：第一特别自律，能坚守最佳实践，跟人性的懒惰和走捷径做对抗。第二他在全世界范围内研究和学习最佳实践和最好的方法论。

G: 他说DeepSeek的出现不是练葵花宝典，是很早就构建集群能力、做链路优化，才有低成本和高效率。陆奇最近又强化了一个观点：研究等于能力，不是研发等于能力。在人工智能时代，研究等于认知，认知很容易变成能力。

H: 说到组织战略。李想的框架是中间一个圈放规模，外边三个动态变量：用户需求、技术产品、组织能力。只有技术变化和用户需求变化产生结合时，组织变化才必须跟上。不能今天出新东西就调组织。

G: 今年大概一千多亿收入，往后看三到六年思考怎么做到三千亿七千亿。从用户需求看光靠SUV不够，要做家庭轿车和MPV，面向全球。从技术看，车实现全自动驾驶后会成为AI时代营收最高的终端，可能做到千亿美金。

H: AI时代终端有四个特点：三百六十度感知物理世界、认知决策、行动执行、反思反馈。汽车正从智能终端变成人工智能终端。他判断在物理世界范围内，终端企业的价值可能战胜平台企业，因为涉及生命安全和财产安全。

G: 铺这么多摊子会不会太开？他说苹果二零零一年推出iPod时已经有电脑和操作系统了，但收入只有几十亿。理想一千多亿往两千亿走，做这些是合理的。操作系统投了十亿省了五六十亿，太划算了。

H: 他聊了学习能力。第一阶段学丰田工作法和通用研发流程，完成了理想ONE。第二阶段学华为的IPD和三支柱，配合L系列做到了千亿。现在往三千亿走，发现苹果又是更好的榜样。苹果也从电脑公司变成音乐播放器公司再变手机公司，一直在变化。

G: 到二零三零年，他给理想的定位是“全球领先的人工智能终端企业”。加了“终端”两个字。他说在AI时代，尤其是物理世界，知行合一才是更大的价值。不能只知不行。

H: 他也说理想会因为三件事消失：没把握住用户需求，没掌握最好的产品技术，组织能力出现巨大问题。这三个放在一起是很好的系统诊断。战略会上始终有反对意见，有些被停掉的东西团队私下做出成果，他最后还是会认同他们。

G: 接下来是最打动人的部分。李想聊了“能量”。人和人之间能量存在时，争执讨论吵架就是更完善的大脑。能量消失时，这些就变成内耗。到了这个规模和混乱时代，能量比能力比业务都重要。

H: 他分享了组织模式：三到七个人组成支撑。三个人不内卷一致对外，通过吵架形成更强大的大脑。一旦做出判断，三个人形成更强烈的心脏。你缺资源别人补，你缺能量别人给。他和秦致、樊铮就是这么支撑的。

G: 到了理想也一样。早期有他、沈亚楠、马东辉、李铁。沈亚楠离开后马东辉顶上去，但我和李铁必须做他的心力支撑。你去做，任何问题你绝对不会倒在地上，我们帮你撑着。后来谢言加入，五个人形成更强的大脑。

H: 怎么让五个人能量凝结不内斗？他说会促成大大小小的事件让他们以这种方式工作。三到七人最稳固，少于三太少，两人不容易，多于七太多。这也符合AI时代更多小组织形成脑力和心力支撑的趋势。

G: 人和人连接的本质是两个“在意”。第一在意客户在意用户，这是最重要的价值观共识。第二在意身边这几个人。要先对人再做事，而不是对事不对人。

H: 他聊了亲密关系。家里最大变化是十四岁的大女儿，春节后成为第三个支撑。她对事情的理解发生巨大变化，三观完善地形成了，能跟父母讨论人生规划、喜好、对人和事物的理解。他每次聊到大女儿都非常高兴。

G: 当爸爸最大的认识有三点。第一，人是用来发挥的不是用来改变的，每个孩子完全不一样。第二，在亲密关系里是我需要他们超过他们需要我。第三，孩子是用来完善我的，孩子对你没有掩饰，能让你把人看得更全面更透彻。

H: 有了“我需要你比你需要我更多”的意识后，行为会更主动积极。不会等着事情变糟再处理。能量的主动权在自己手里。他说工作体现社会价值，家庭是亲情价值，幸福就是高质量的陪伴，两者相辅相成缺一不可。

G: 他也谈到成长。过去做汽车之家时觉得做好业务就行，资本不重要，结果折在资本上。做理想汽车时他非常注重资本，请最好的财务顾问、律所，设计股权架构和投票权。这不是改变自己，而是增强了一个能力，是成长。

H: 回到AI和人的关系。李想说人类和AI应该是合作关系不是矛盾关系。人类能量有限，应该用于处理智慧、处理跟万物的关系、做熵减。让AI处理复杂信息、压缩知识、自动化做行动。工厂里也不是人类去做焊接涂装，机器取代了人类的地位吗？没有。

G: 他特别区分了智能和智慧。今天解决的是智能问题，没解决智慧问题。很多聪明的人一点都不智慧。智慧是我们跟万物的关系。你没去过森林认真住过几天，就觉得木头只是做筷子做桌子的，不会意识到它是不同的生命。

H: AI能感受幸福吗？当然不能。至少今天这个架构不具备自主意识。但他认为今天这个架构对人类挺安全的，信息安全财产安全人身安全都可以靠人类预期解决。很多人是多虑了。你想根本改变它的输出，得重新训练，光靠提示词非常有限。

G: 人类和AI的关系是个未解的问题。如果AI解决了就统治人类，如果人类解决了人类仍然统治文明。但他有信心人类可以解决，前提是把智慧当成重要特质去发展。只要人类掌握智慧制高点，仍然是文明带领者。

H: 在AI面前什么值得保留？他说所有人性都应该保留，无论好的坏的。没有坏的就没有好的，优点另一面就是缺点。只想要好的放弃不好的并不成立。好的不好的都是特质，文化的特质、生命的特质。这样才是活生生的人。

G: 最后他说了一段特别朴实的话。他九成的状态和思维方式跟上高中时差不多，遇到问题去解决问题，去解决别人不愿意解决的问题。只是解决的问题在变大，服务的用户在变大，公司规模在变大。
