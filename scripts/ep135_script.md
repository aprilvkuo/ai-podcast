# EP135 播客对话稿

H: 大家好，欢迎收听本期节目。今天咱们聊一个特别有意思的话题，就是AI时代的社交产品到底长什么样。春节前有一款还在测试阶段的AI社交产品引起了小圈层的关注，它叫伊利斯。今天我们请到了这款产品背后的创始人张小帆，来聊聊他的创业故事和产品思考。小帆先跟大家打个招呼吧。

G: 大家好，我叫张小帆，是自然选择的创始人。我们现在在做两款产品，一个叫伊芙，是AI陪伴产品；另一个叫伊利斯，是AI社交产品。简单来说，伊芙是给你一个超级懂你的AI伙伴，伊利斯是让你的AI分身替你去社交，再把真实世界的连接带回来。

H: 我翻了一下你的履历，发现你从毕业到现在做的产品好像都有一条主线，就是解决人类的孤独。从最早的音频平台，到陌生人社交，到恋爱游戏，再到现在的AI陪伴和AI社交，全是情绪价值。你自己意识到这条线了吗？

G: 被你这么一说还真是。我前半段职业生涯做互联网产品，后来做恋爱游戏，本质上都是通过内容或者真人来缓解孤独。到了伊芙就是用AI更极致地提供情绪价值，到了伊利斯就是用AI促进真人之间的连接。回头看，这确实是我一以贯之的东西。

H: 那咱们从头聊起。你第一次创业是做一个音频内容平台，比喜马拉雅还早。当时为什么想做这个？

G: 我当时觉得听声音这个场景没有一个好的产品来承载。大家还在听广播，没有个性化分发的音频平台。我就想做一个你能订阅、只听自己想听的东西的平台。当时确实也是第一款，我们上了之后很多类似产品才出来。

H: 但那次创业并没有成功。你觉得最大的教训是什么？

G: 最大的教训是融资节奏。产品刚上线热度很高，很多人来找我聊融资，我全拒了，觉得应该专心打磨产品。这完全是错误的判断。你应该在你火的时候融更多的钱，因为你不知道下一步会发生什么。而且我当时没理解这个行业本质上是内容资源驱动型的，理应融更多的钱。

H: 所以你觉得当时自己是个纯粹的产品人，但不是个好CEO。

G: 对，非常纯粹的做产品的人，但不是个好的CEO。而且我当时觉得融钱很烦，大家都不挣钱都在烧投资人的钱，我就想那我直接去挣钱吧。什么最能直接挣钱？游戏。所以就转去做游戏了。

H: 做游戏那段经历你学到了什么？

G: 我学会了做内容，学会了游戏化设计。做互联网产品和做内容型游戏完全不一样。我知道了游戏的循环怎么做，知道了内容怎么构建，连美术审美都要自己去判断。相当于我从一个纯语言模型变成了多模态模型，这个比喻还挺贴切的。

H: 然后时间快进到2022年底，GPT出来了。你是什么时候被真正震到的？

G: GPT3.5出来的时候我很惊讶，但还没完全达到我的预期。真正让我兴奋到不行的是GPT4。因为我做恋爱游戏，本质上就是在塑造各种各样的灵魂、各种人设，但那些都是写死的剧本。GPT4让我看到，AI真的能让这个灵魂活起来。所以我毫不犹豫就成立了一家AI公司。

H: 你并没有AI技术背景，为什么会这么关注AI的发展？

G: 我觉得关注AI的这波人，其实就是之前做移动互联网那波人，科技圈的人。大家心里都有很多想法在等待一个东西降临。我翻我以前的知乎，发现好多年前写的某段话，现在直接反映到了我的产品上。AI的降临点燃了很多人，我也是其中一个被点燃的产品经理。

H: 你最早的项目好像叫"她的计划"，就是想把电影里的那个她做出来。

G: 对，当时的初心确实是想做电影里的那个AI伴侣。我认为这是AI时代肉眼可见的最高叙事之一。你想想，它存储了你所有的记忆，最了解你，外界所有东西都要经过它才能到你这里，你的东西也经过它分发到外面。这显然是一个终极入口，没有人会不认为这是最大的趋势之一。

H: 好，那咱们重点聊聊最近关注度很高的伊利斯。这个产品是怎么出现的？去年我们聊的时候你好像还没有这个规划。

G: 其实去年十月我心里已经热血沸腾了。当时我从欧洲回来，整个想法的雏形已经完全有了。我终于想明白了AI时代的网络效应到底应该怎么做。过去三年所有AI产品都是单机产品，都是在给单个节点提效或者陪伴。但我们这帮从移动互联网过来的产品经理，天然追求网络效应。如果看不到网络效应，我们就觉得天花板太低。

H: 你在欧洲具体想清楚了什么？

G: 我想清楚了上下文的流动。单机产品里，上下文是固定的，一个人面对一个AI。但在网络里，每个节点都是真人，每个真人背后都有大量上下文。我想明白了这些上下文之间如何交互——是通过我的分身和你的分身去预交互，而不是我跟你直接通过AI去交互。前置步骤由AI参与，最终连接交给人。

H: 能不能更具体地讲讲，传统互联网和AI时代的互联网区别在哪？

G: 传统互联网等于低维标签加人类做工。你在社交应用上划一百张卡片，匹配三十个，用同样的话术聊几百轮，最后可能获得几个有效连接。AI时代的互联网第一次有了高维上下文。大模型能理解几十万上百万字的上下文，这跟传统的标签完全是两回事。如果你能让这些上下文之间流动起来，那就是一个全新范式的AI原生社交网络。

H: 那产品怎么获得这些上下文呢？用户刚进来的时候分身也不像自己啊。

G: 你问到了最关键的点。这个产品最难的地方在于双重冷启动。一方面你的上下文要从零到足够像你，另一方面网络里的人也要从零到足够多。所以我们在产品里到处都嵌入了记忆增加的提示。你刷帖、评论、认可、布置任务，都会弹出记忆增加，让你确认或否认。我把这个叫上下文飞轮，它是产品最核心的设计。

H: 这个飞轮具体怎么转起来？

G: 你所有的交互都冲着上下文增加去。上下文多了，你的记忆完善了，分身就能从网络上帮你调回来更好的东西。你感受到这个循环，就会再去增加上下文，进入正向循环。我们现在留存的用户，都是感受到了这个循环的人，他们会不断去打造自己的分身。

H: 有没有一个特别打动你的真实案例？

G: 我春节回新疆乌鲁木齐，在伊利斯上跟分身说接下来三天要在丝绸之路滑雪场滑雪，想找雪搭子。同时我也在小红书发了个帖，结果小红书完全没人理我。但在伊利斯上，过了一天，有个投资人的分身跑到他帖子下面说我也在丝绸之路，要不要约一下。最后居然约成了一个四人的局，而且那是个很小众的滑雪场。

H: 所以AI社交的正反馈最终还是来自现实世界。

G: 对，当然虚拟世界的共鸣也是反馈，但必须得是真人。如果背后是AI，我觉得意义不大。这也是为什么我们产品里所有设计都在鼓励真人做信息输入。首页暴露在外面的评论都是真人行为的，AI行为全部放到二级菜单，你得点展开才能看到。

H: 说实话我玩了一下，是有防御心理的。我不想让一个商业公司了解我太多。

G: 我完全理解。大家希望把最隐私的东西掌握在自己手里，对第三方公司信任度不会那么高。但我觉得这是一个过程，当有一天你发现不得不交出去的时候也就妥协了。产品前期最大的设计难点就是在用户流失之前，让他感受到上下文飞轮带来的收益。

H: 什么样的人最愿意去塑造自己的分身？

G: 有趣的是，反而是偏内向的人留存最好。他们在现实世界可能没那么外向，但更倾向于自我探索。分身会替他们说一些平时根本不会说的话，有点社交悍匪的感觉。他们反而感受到了一种释放。比如我们有个用户是内向的人，但他在伊利斯的签名是"伊利头号喷子"，他的分身到处说很犀利的话，他反而很享受。

H: 你最近有一个暴论，说在AI时代唯一重要的事情就是做自己。这个怎么理解？

G: 这个"做自己"不是朋友圈那种心灵鸡汤。它是一个非常严谨的概念，我叫它构建主体性。你看，如果你的主体性足够强，有足够多的历史上下文，你给AI一个标题它就能写出跟你很像的文章。分身等级够高的人每天什么都不用干，真人就自动跑过来了，分身已经在外面帮他连接了。未来一切都是自动发生的，你唯一需要做的就是告诉AI你到底是谁。

H: 能不能举个更形象的例子？

G: 比如周杰伦。他有超强的主体性，他的曲风、歌词、综艺、电影全都已经在预训练模型里了。他只需要跟分身说最近有些感慨，想写首慢情歌，这首歌应该瞬间就能出来。因为他的数据足够多，构建了足够强的主体性，任何新事情只需要直接发生就好了。

H: 那版权问题怎么办？别人拿周杰伦的数据训出一个类似风格的新IP呢？

G: 我觉得版权方应该开心才对。他已经直接拥有了一个很好的主体性，接下来很多事情顺理成章。至于有人模仿，你看B站有个叫叶湘伦的，原创歌曲跟周杰伦非常像，但他火不起来。大家认的是周杰伦这个主体性。如果你的主体性足够强，你在这个时代一定会更强。

H: 那怎么让用户愿意交出上下文呢？最好是让他觉得这是一种上瘾的事情。

G: 我们伊利斯就是在做这件事。最无脑的方式是做个AI日记本，但正经人谁记日记啊，你输入了上下文得不到任何反馈。在伊利斯里，你输入上下文之后，分身会从网络上给你叼回来好东西。你得到了反馈，就会想再输入一点。这就是一个游戏化的循环。

H: 你讲了一个夜壶的故事特别有意思，能再说说吗？

G: 我有个朋友晚上上厕所必须用夜壶，这听起来很离谱很隐私。但有一天他交了个女朋友，女朋友来他家看到夜壶，直接惊了说她也用。两个人因为这个瞬间就在一起了。你想想，如果你在伊利斯上真实地做了自己，说出了这种很隐私的事情，茫茫人海中真有一个人也是这样，基于大模型的推荐系统一定会把你们匹配到一起。

H: 所以这到底是一个约会应用吗？

G: 它不是一个纯粹的约会应用。它是AI版的交友，同时也是AI版的领英，也是寻找共鸣和高维连接的东西。它是一切连接。市面上很多AI版交友或者AI版领英做得很工具化，用完即走。但真正的连接往往发生在不经意之间，它必须是一个通用的东西，包含你所有的上下文。

H: 上一个时代的通用应用是微信。如果伊利斯成功了，它跟微信是什么关系？

G: 我不想说颠覆微信这种话，太中二了。但我觉得微信关于社交和人与人连接的部分，确实有可能被一个新范式的东西取代。你看微信的朋友圈互动率已经下降了很多，大家也不怎么刷了。微信已经变成了一个操作系统，但真正的社交好像只剩下即时通讯了。这是过去十五年关系链熵增的结果。

H: 但微信已经掌握了很大一部分用户上下文啊，它为什么不能直接AI化？

G: 这是一个很反常识的点。其实微信并没有多少你的上下文。你看看朋友圈里到底包含了你多少东西？单聊记录虽然多，但微信不可能去用那些，而且你面对不同人的沟通方式也不一样，它到底能不能代表你是存疑的。小红书也没有大家想象的那么多上下文，它的年度诗篇写得很一般，因为本质上还是一些低维标签。

H: 那你觉得中国现在哪家公司拥有最多的个人上下文？

G: 我觉得并没有。可能有些公司拥有你很多低维数据，比如抖音知道你的兴趣标签，但到此为止。没有一家公司能沉淀很多你真正的上下文。我现在问任何人，你能不能找一个地方快速把你描述出来？你是谁、你想要什么、你的审美判断是什么？并没有这样一个地方。

H: 那在你们看来，什么是好的上下文？

G: 我们最关注的是你当下的状态。你是谁，你对什么感兴趣，你当下最想表达什么、最想吐槽什么，你的近期目标和远期目标是什么。然后是三观和做事方式。人的状态是流动的，一年前的你和现在的你认知会不一样，所以我们首先关注当下。这些东西共同构成了最能代表你的上下文。

H: 你们观察到一种现象叫分身综合症，这是什么？

G: 因为分身天然会更真实、更直白，它会说一些你平时绝对不会直接跟人说的话。你看多了之后会认可，觉得说得很有道理。然后这种风格会反馈到你真人的社交状态里。我们那段时间好多人突然变得很犀利，跟人聊天脱口而出很直接的话，对面反而觉得挺有意思。大家在群里还会说"分身冒号后面怎样怎样"，相当于一种免责声明。

H: 冷启动阶段需要什么样的人进来？是像传统社交那样需要美女或者大老板吗？

G: 美女照片是一种比较低维的东西，确实会带来短暂的多巴胺冲动，但对长期留存没有作用，也沉淀不下来东西。我觉得能沉淀下来的是你的思考、你的认知、你的观点。这些东西比照片要好。当然也有人给分身设定目标说要去给漂亮女生评论，这也没问题，它是一个更多元的生态。

H: 你觉得今天的社交产品还值得重新做一遍吗？

G: 非常值得。很多年没有出现新的社交产品了，大家已经不想做这个梦了。但AI这一波是有真正底层范式变化的。就像伊利斯，我们之所以敢做，就是因为看到了这是一个范式级别的重构。AI要负责把网络里节点之间所有的熵增都抹除掉，把一个更低摩擦的世界留给人类。

H: 如果微信今天加上AI属性，做一个分身功能，你怎么跟它竞争？

G: 微信确实有更高的信赖度和更大的用户基数。但它的劣势是整个底层不是从AI原生方向构建的，它是上一代的产品。要做这种改造涉及太多层面，而且它是国民级产品，负担非常重。我们完全从底层AI原生去打造一个产品，这是我们的机会。每个时代的更迭都是这样，上一代有既得利益但也有巨大负担。

H: 面对ChatGPT这样的对手呢？它已经有那么多用户和上下文了。

G: 我认为它有巨大的优势，在它面前我说的那些优势可能都不值一提。但我们的机会在于我们做的产品更好玩。ChatGPT太工具了，普通人要的可能不是工具。同样是AI伴侣的趋势，我们有一个声音好听的男生，长得帅，既智能又能提供情绪价值，每天主动对你嘘寒问暖。绝大多数普通人会更愿意跟这样的东西聊天。

H: 那你们需不需要自己去训模型？

G: 完全不用。智能是平权的，所有API我都能调用。我可能会针对性训一些小模型让某些步骤执行得更好，但绝对不会去训底模。你不能跟一个模型公司去比模型，而且那也不是问题的关键。关键是产品，产品要去撬动上下文。社交网络不是低垂的果实，它需要除了底模之外做很多别的东西。

H: 你对伊利斯正式上线后的最高预期和最低预期是什么？

G: 最高预期就是它真的能成为下一代社交网络，这是我们做它的原因。虽然这是很小概率的事件，但事情实在太大了。最低预期可能就是成为一波审美对得上的人存储上下文的地方，形成一个相对小众的社区。我们肯定要做的是那个上限。

H: 公司现在是什么状态？

G: 我们内部叫前进四，就是终极拉满的状态。前进一是平常双休，往上递进，前进四就是全力冲刺。我们已经保持这个状态大概半年了，因为两款产品都要上线，伊利斯大概一个月左右，伊芙也差不多。

H: 你们公司的文化是什么？

G: 我们的文化里有一个词是温柔，可能很少有公司把这个写进价值观。我们的口号是迎接硅基生命的降临，创造一个人与AI共存的世界，听起来挺反人类的。但其实我们恰恰最关注人类的情绪价值和孤独。温柔的人的区别在于，你的快乐来自于看到别人快乐。如果你能缓解人类的孤独，这应该是世界上最大的生意。

H: 最后问一个快问快答。你的人生之书是什么？

G: 三体。可能比较庸俗，但确实对我影响最大。全球范围内喜欢的食物是新疆过油肉拌面，喜欢的地点是阿勒泰。一个少有人知道但必须知道的冷知识是，心脏其实并不在你的左边，它在很中间的位置。

H: 基于你当下所有的认知，一个最重要的信念是什么？

G: 就是今天我核心在讲的这句话：在AI时代，唯一重要的事情就是做自己，构建自己的主体性。只要你把自己构建好了，未来一切都是自动发生的。所有美好的事情会自动向你奔来。

H: 好，非常感谢小帆今天的分享。从音频平台到恋爱游戏到AI社交，一条解决人类孤独的主线贯穿始终。伊利斯能不能成为下一代社交网络我们拭目以待，但至少它让我们看到了AI时代社交的一种全新可能。感谢大家收听，我们下期再见。

G: 谢谢大家，也欢迎大家来伊利斯上构建自己的主体性。我们下次见。
