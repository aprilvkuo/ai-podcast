# EP129 播客对话稿：智谱CEO张鹏——从清华实验室到全球大模型第一股

H: 大家好，欢迎收听本期节目。今天聊一家特别的公司——智谱。2026年1月8日，智谱登陆港交所，成为全球第一家上市的大模型公司。

G: 更巧的是，上市前夕创始人张鹏出差途中摔断了腿，拄着拐杖来接受采访。西方有句老话，"摔断一条腿"就是祝你好运。结果几天后，真成了全球大模型第一股。

H: 张鹏的履历特别简单，98年进清华，之后再没离开过。毕业后在计算机系知识工程实验室工作，说白了就是搞人工智能。

G: 2015、2016年是个关键节点。实验室走出去的唐文斌、杨沐创办了旷视，成了上一代人工智能四小龙之一。大家就在内部讨论：上一代的路走到头了，下一代到底是什么？

H: 张博院士当时画了一个二维象限，特别形象。上一代人工智能解决的是"我知道我知道"的问题，就是人脸识别、语音翻译这些单点技能。

G: 再往外是"我知道我不知道"，最外面是"我不知道我不知道"。上一代技术没有脑子，只有技能。所以结论是：下一代要做认知智能。

H: 这个想法2016年就成型了，但真正动手是2017年。那时候学校体制内人员开公司不被允许，大家只能偷偷摸摸干。

G: 但张鹏他们不想留首尾，想走正式的官方路径。正好2018年初，教育部等部委出了文件，允许科研人员用已有成果做科技成果转化。他们成了第一个吃螃蟹的人。

H: 这个螃蟹真不好吃。从拿到文件到公司注册，整整走了一年半。主要耗在谈分配比例上：三七开、二八开还是一九开？科技成果到底值多少钱？

G: 学校那边也麻爪，说操作细节我也不知道，你们是第一个来聊的。双方互相理解、互相配合，最终2019年6月把公司走通了。整个清华计算机系，他们是第一家。

H: 转出来之前，他们在实验室里已经挺能赚钱了。做一个科技情报平台，客户包括谷歌、这些国际大厂。一年横向经费接近两千万。

G: 但张鹏说，赚钱不是目的。他们真正想做的是借这个场景探索认知智能。谷歌找他们做的事特别简单：告诉我未来三到五年，某个领域哪些技术会成为热点。

H: 这本质上是个预测问题，预测一定需要认知能力。理解旧知识、综合推演、产出新知识，跟人类知识增长的逻辑一模一样。

G: 2020年，分水岭来了。GPT-3发布，正好赶上公司一周年。他们请张博院士来座谈，张鹏当面问：您怎么看GPT-3？

H: 张院士给了非常高的评价，说是机器学习里程碑式的进步。但同时指出一个核心缺陷——GPT-3会一本正经地胡说八道，它不知道自己不知道。

G: 智谱没干等着。2021年搞出了自己的算法，叫GLM。特别巧妙，把双向注意力和单向注意力统一起来了。

H: 简单说，以前的模型要么是填空式的，要么是续写式的，GLM把两件事合二为一。而且大规模训练时稳定性更好，做量化时精度损失更小。

G: 2022年，关键决策来了：要不要训练一个千亿参数的大模型？GPT-3训练成本两千多万美元，智谱算下来也得千万级人民币。风险很大。

H: 最终决策是：必须做，而且必须自己做。结果他们只花了四百万人民币，加上人工杂费大概一千万。GPT-3的十四分之一。

G: 这就是中国团队的优势，大家都会抠细节、要效益、控成本。2022年8月，他们把模型开源了。

H: 为什么开源？张鹏说得很实在：这东西捏在手里，短时间内也变不成钱，让更多人知道更重要。而且当时中美关系还没那么复杂，开源是很容易接受的文化。

G: 效果非常好。斯坦福李飞飞团队的年度报告里，唯一排名靠前的中国模型就是GLM-130B，跟GPT-3互有胜负。

H: 但投资人完全听不懂。问的都是：这东西能变成钱吗？大环境这么差，要不你们把估值降一半？张鹏说，肯定不会降。

G: 转折在2022年11月30日，ChatGPT上线。春节前在国内彻底火了，正好帮了智谱一个大忙。

H: 之前跟投资人解释半天，人家将信将疑。现在直接说：你看过ChatGPT吧？我们做的就是往那个方向去的。一下子从无人问津变成投资人追着问。

G: 2023年就是"百模大战"了。张鹏感受很复杂。一方面特别兴奋，大家不用教育市场了。另一方面又焦虑，怕市场走向极端后塌掉。

H: 他说了一句特别清醒的话：我怕的不是自己做不出来，而是烈火烹油之后剩下一片狼藉。如果市场都没了，你做得再好也没用。

G: 2023年还有个有意思的争论：通用模型和垂直模型谁对。张鹏说，到今天回头看，这是个伪命题。所谓的垂直模型在市面上根本没什么声音。

H: 他跟王小川在机场摆渡车上通过电话，王小川想推广L0、L1、L2分层概念。张鹏认同垂直化可以做，但一定要基于一个足够好的基座。

G: 商业化路径上，智谱做了个重要选择：不深入做面向消费者的产品。张鹏分析很直接：在美国，ChatGPT每月收二十美元，大把的人交。在中国不可能。

H: 中国消费者端付费意愿太差了。群雄混战，最后必然陷入倒贴、引流、补贴、让用户薅羊毛的状态。他们投过流，也挣了点会员费，但算完投入产出比很不合算。

G: 那智谱怎么赚钱？他们很早就提出"模型即服务"，范围比现在大部分人理解的要广。不只是云端接口，还有本地化部署、软硬件结合的产品。

H: 企业服务占百分之六十，政府只占百分之二十。中国前十大互联网企业里有九家是他们客户。张鹏说，企业才是生产力最集中的地方。

G: 说到开源，智谱从2022年就开始了，到现在将近六七十个开源项目，下载量超六千万次。但DeepSeek出来后，彻底把开源和免费画了等号。

H: 很多客户问：人家都开源不要钱了，你为什么还收我钱？张鹏说，只能用时间证明。大部分客户自己折腾一圈又回来了。

G: 因为开源模型不等于商业化服务。部署、集成、运维都需要专业能力。DeepSeek也不提供商业化服务，你顶多拿它当聊天机器人问一问。

H: 2025年初，DeepSeek给了整个行业很大冲击。张鹏说春节一回来就密集讨论反思。结论有三条：强化学习下的力气不够；工程优化可以更极致；下一个范式的探索应该更大胆。

G: DeepSeek尝试跳过微调直接做强化学习，智谱也试了，但结论是暂时还不能完全扔掉微调。不过后面确实加强了强化学习，4.5到4.7一步一个台阶上去了。

H: 关于Transformer是不是终极答案，张鹏态度很明确：肯定不是。现在的计算方式消耗太大，还不是最完美的。

G: 但他也强调，在现有架构下能做的事还太多。数据工程、算法调优、注意力机制的各种变种，空间依然很大。

H: 过了那个"浅浅挖一挖就有金矿"的阶段了，但不代表没有果实，只是需要更深的功夫。柳暗花明，别轻易放弃。

G: 关于扩展定律，张鹏很清醒。他说扩展定律只是现象描述，没有严格科学依据。2023年大家信暴力美学，简单粗暴堆算力。

H: 但成本先受不了了，非常贵。这时候两条路：一条是融更多的钱、讲更大的故事；另一条是优化。OpenAI坚决走第一条，智谱两条都做。

G: 团队扩张很快。2023年两百多人，2024年四百人，现在八百多人，每年翻一倍。2025年以前保持一个记录：每年搬一次家。

H: 张鹏说，以前一百多人时所有人他都认识。搬到两层楼后，有一批人他已经叫不上名字了。这就是企业从几十人到几百人必须跨过的管理坎。

G: 张博院士讲过，创业企业有几个坎。五十人是一个坎，只要挣到钱就行；两百人是一个坎，分工之后管理成本上来；五百人以上又是一个坎，信息传导变长。

H: 任何一个坎过不去，企业可能就完蛋了。张鹏说他们比较幸运，没犯什么大错误。但上市又是一个新的坎，合规要求非常高。

G: 上市这件事，其实在公司成立第一天的规划里就有了。他们给自己做过模型，每年增长百分之一百到一百五，推到哪一年进入三年业绩期考核。

H: 真正启动是2022、2023年。张鹏说，上市不是终点，后面还有很多路要走。他是个天秤座，天生追求平衡。

G: 有人评价智谱像水泥，能干得很漂亮，但没有太多情绪价值。张鹏觉得还算中肯。就像清华理工男，聪明、能干，就是不够有趣。

H: 他们也试过更酷一点、更吸引眼球，但基因决定了，最终还是在开发者和工程师群体里口碑最好。踏实，工程师文化。

G: 问到中国谁真正在追求通用人工智能，张鹏说不好判断。每个人定义差别很大。对智谱来说，本质就是那句口号：让机器像人类一样思考。

H: 但最终，能思考的机器还是要反过来赋能人类社会。他们不光在实验室敲代码，也要卷起裤管下秀馆，去客户现场解决实际问题。

G: 张鹏回忆了一个让他感慨的瞬间。2021年底，他一个人跑到深圳待了半年，为了一个大客户。正好赶上模型开源、发布、融资一系列事情。

H: 他回去时不是空手回去的，带着几千万的客户合同。当时没觉得什么，年底回头一想，真不容易。两点一线都不能三点，但最终还是把事做成了。

G: 还有一个瞬间，发布会上让智能体给观众发红包。结果出了个小故障，红包金额填错了一位数字，但不影响，还是发出去了。

H: 后来有人评论说，这是人工智能给人类发的第一个红包。张鹏说那一刻挺有成就感的。

G: 今年7月发布4.5模型时，现场只有几十个人，非常低调。但海外评价极高。美国公司开始用他们的模型，甚至有人拿开源模型去蒸馏裁剪，套壳装作自己的。

H: 张鹏说，你本质上把事做好，大家认可你，自然会有回响。从4.5开始，他们不再开大型发布会了。某种程度上，也是DeepSeek教大家的。

G: 对于未来，张鹏判断：2027年可能开始具备那种状态——一个有各种能力的脑子，装上手脚，跟世界交互，反馈变成强化信号，立刻学习修改模型。

H: 之后可能还需要五到八年调整效率、学习成果和安全性。他说，我们永远不会忘记目标就是通用人工智能。融资的钱都是盘缠，路上要走很远。

G: 必须找到同样有信念的人一起走。如果只是为了钱，很难坚持长期做这件事。人很容易忘记原来坚持的东西。

H: 他特别提到，不要"曲线救国"。先找个确定性市场赚一笔，再回来追求通用人工智能？没必要。信仰这个东西，绕个路找个理由，很容易就丢了。

G: 从技术角度也一样。上一代人工智能在视觉上确实突破了，比人还好，但不解决问题。自动驾驶也是，大家重新认识了驾驶到底是什么行为。

H: 经典自动驾驶是闭环控制系统，感知、决策、输出。最怕各种意外情况。你训练一百万遍路上碰到车怎么办，但很难训练路上突然穿过一只兔子怎么办。

G: 这就是认知智能和感知智能最大的区别：泛化能力。通过有限样本学习，总结出的东西能搬到没见过的情况上去。有脑子，能举一反三。今年的图灵奖理论叫"经验时代"，含有试错过程的数据对认知能力更有价值。

H: 张鹏说，现在大模型的学习越来越强调预训练之外的微调和后训练。他们提出了L1到L5的阶梯：L1预训练死记硬背，L2对齐和推理靠监督微调，L3自学习靠强化学习。

G: L4是自我认知，知道自己不知道什么。L5是类似人类的意识。现在在L3的位置上。扩展定律的核心也在变：L1是参数量数据量算力，L2是推理计算量，L3是强化学习规模。

H: 下一个范式可能是在线学习。推理和训练之间没有明显界限，连贯起来形成完整闭环。多模态也是必然趋势，不只是视觉和语言，代码、智能体执行步骤、机器人控制都是跨模态的。

G: 张鹏认为多模态统一一定是终极形态，但未必基于Transformer。加上在线学习，可能就真看到曙光了。问到上市会不会让公司变平庸，张鹏说不会。

H: 有人说大模型公司上市是大逃生，怕2026年泡沫破。张鹏反问：假设它是泡沫，上市能救我们吗？能救投资人的钱包，那不是救我。

G: 他又问：你怎么定义泡沫？最近的泡沫是互联网。但互联网泡沫破了，留下了什么？网络基础设施、技术革新、无数产品，都是那个年代留下的。

H: 说到底，大家担心的是自己兜里的钱。如果投资不够，凭什么叫泡沫？中国投入是美国的几十分之一，远远不够。

G: 朱啸虎说大模型六小龙可能最后不如上一代四小龙。张鹏说，这结论下得太早了。从2023年算才三年，从公司成立算才六年多，这么早就盖棺定论？

H: 天底下的路不止一条。不要用既有经验框新东西。很多错失的机会，就是因为被旧规则束缚住了。

G: 最后问他，一百年后如果智谱出现在人工智能历史书上，希望怎么被书写？他说：智谱是通用人工智能历史上的一个先行者。

H: 我追问，为什么不是创新者？他说，先行者一般就是创新者，就是开路的人。这六年半，他们确实一直在开路。

G: 从清华实验室里那个"下一代人工智能到底是什么"的讨论开始，到港交所的敲钟台。机会永远留给有准备的人，哪怕在海上漂着，有块木板飘过，你也得扑腾两下才能抓住。

H: 好了，今天的节目就到这里。智谱的故事也是中国大模型行业的缩影——从无人问津到百模大战，从暴力美学到精细优化，从开源之争到商业化落地。感谢大家收听，我们下期再见。
