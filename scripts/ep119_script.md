# EP119 双人播客对话稿

H: 大家好，欢迎收听张小俊商业访谈录。我是小俊，这档节目由语言及世界工作室出品。今天我们聊一个硬核话题——人工智能的算法与架构创新。嘉宾是我们的老朋友，MIT在读博士杨松林，研究方向是线性注意力机制。

G: 大家好，我是杨松林，目前在MIT读博士，主要研究高效注意力机制，更具体说就是线性注意力。上次节目播出后很多人叫我"线性注意力之母"，可能是因为我在这个领域做了很多工作，那个开源库闪电注意力业界也在用。

H: 松林，为什么2025年算法创新突然变得这么重要了？之前大家不是都在堆算力、堆数据吗？

G: 对，之前数据能一直堆的时候，根本不需要动算法，大家只要买卡就行了。模型继续扩大，继续加数据，谁都不需要去动架构。但现在数据撞墙了，算力也有限，就不得不重新回来雕模型架构。

H: 这个"雕"字很有意思，你经常用。是研究员之间的一种自嘲文化吗？

G: 对，有种"雕花"的自嘲感。之前杨植麟说不要时尚雕花，但现在没办法，算力不够数据也有限，只能雕。不过雕架构确实有用，深度求索的混合专家模型出来之后，大家已经把它变成共识了。

H: 中国因为算力相对有限，反而让算法创新走在了世界前沿？

G: 是的，国内算法创新肯定更强。国内没有那么多卡，对效率要求更高，更有动力尝试高效的线性注意力变种。硅谷有些公司卡太多了就懒得搞。三驾马车总得有一辆跑得快一点，他们有算力也能凑合跑。

H: 好，切入正题。最近Kimi、MiniMax、通义千问都发了新模型，你参与了Kimi和通义千问的部分工作。先给大家讲讲Kimi线性注意力这篇论文？

G: 这篇文章的线性注意力模块叫KDA，全称Kimi增量注意力。这名字挺有梗，明显对标深度求索的稀疏注意力，特意取了Kimi开头的名字。核心问题是年初深度求索R1和Kimi 1.5发布后，强化学习会产生几万个词元的长思维链，如果每层都是平方注意力，推理太贵了。

H: 具体贵在哪？你们改造的核心目标是什么？

G: 每层要存很大的键值缓存，推理几万个词元总时间复杂度是平方的。核心目标就两个：跟全局注意力比性能不能掉点，同时推理速度要快很多倍。在这种长思维链和今年智能体的大背景下，混合注意力非常有用。

H: 能不能给大家画个重点，KDA到底做了什么？

G: KDA基于我去年门控增量网络的工作。之前受限于效率，一个注意力头下所有维度共享一个衰减率，这是粗粒度的。张宇把它换成了细粒度的——每个维度有自己的衰减率，每个维度的隐藏状态有独立的更新频率，能更好地利用有限的隐藏状态。

H: 这个设计的灵感来源是什么？

G: 其实KDA就是把我前两个工作的思路合并了。我之前有个门控增量注意力，就有细粒度衰减率。但当时算法和并行化没优化好，被迫用粗粒度。今年条件成熟了，大家就觉得可以重新把细粒度衰减率引回来。

H: 最初效果怎么样？

G: 张宇先试了一大堆混合注意力的混法，发现换门控增量比其他的好。然后Kimi内部有个类似通关的机制，你在一个规模下表现好，就要到下一个规模继续验证。最开始混合门控增量有些地方不如全局注意力，后来换成细粒度衰减率后提升就挺大了。

H: 论文里每三层KDA插一层全局注意力，三比一这个比例怎么确定的？

G: 三比一现在快变成共识了。MiniMax之前是七比一，全局注意力层数不够，长文本保证不好。字节也发了论文专门研究混合架构需要多少全局注意力，结论也是三比一最好，而且门控增量这个模块比其他的好。

H: 千问3下一代也用了三比一加门控增量？

G: 对，不同厂商探索出来都觉得这个比例更好。MiniMax可能最开始验证不充分，用了更激进的七比一方案，现在基本都回到三比一了。我觉得三比一应该是不共识的混合注意力里面的一个共识了。

H: 混合注意力有没有短板？

G: 唯一的问题可能是多跳推理。MiniMax也承认了，混合线性注意力在长文本多跳推理上有缺陷。因为多跳推理比较吃词元之间的关系，比较吃全局注意力层数。但据我所知，其他任务基本不会比全局注意力差。

H: 那我们来聊聊各家公司的不同选择。MiniMax最戏剧性——年初用线性注意力，最近的M2又退回全局注意力了。

G: MiniMax团队很开放，分享了很多经验。他们第一版只看MMLU这些指标，发现闪电注意力表现好效率又高就上了。但那个闪电注意力其实很弱，机制还停留在两年前。后来做多跳推理发现掉点非常大，最近想做智能体和编程，就暂时退回全局注意力了。

H: 但他们说还在继续探索混合注意力？

G: 对，说不定M3又变回混合架构了。历史就是螺旋上升的，一套技术方案要经过很多验证才能定下来。M1当时验证不充分，比较草率地上线，后面发现多跳推理效果不好就退回来，这很正常。

H: 深度求索的稀疏注意力跟你们的混合注意力，各自优劣是什么？

G: 稀疏注意力推理能力更强，但不能省键值缓存。混合注意力可以省很多键值缓存，因为绝大多数层都是类似循环神经网络的层。同时还能提高推理效率，加大批处理大小。

H: 有没有可能把两者结合起来？

G: 我之前在知乎写过，为什么不能结合呢？让稀疏注意力取代混合注意力里的全局注意力层，这样就不需要全局注意力的复杂度了。剩下层的键值缓存用线性注意力打下来。这可能是我心中最理想的高效架构。

H: 为什么工业界还没人做这种结合？

G: 据我所知工业界没人在同时结合两者，但学界有一些探索。深度求索选了稀疏，Kimi选了线性，这可能也是阶段性的，未来大家会探索一条新路把两者结合。现在也不是非此即彼的关系。

H: 稀疏注意力选不准的核心瓶颈在哪？

G: 学习难度。从头训练的话梯度不太准，学着学着就选不准那个块了，有各种稀疏梯度的问题。所以深度求索最近那个稀疏注意力要用蒸馏方式，让一个训好的全局注意力教师模型来教学生怎么选词元，这样就选得非常好了。

H: 我们来考古一下线性注意力的发展史。你读博前花了半年读老论文，你管这叫考古？

G: 对，我特别喜欢考那些古代的论文。一年前的论文叫老论文，五年前的叫古代论文。我申请完博士有半年自由时间，把这个领域值得看的文章基本全读了一遍，大概读到201几年的。

H: 这个做到的人很少。你为什么觉得必须全部读完？

G: 我觉得一定要把领域里值得看的文章全部看一遍。不同人有不同的研究哲学，但我是那种必须把握整个领域脉络的人。正因为非常熟，碰到问题也知道怎么解。

H: 线性注意力最早是2020年发明的？

G: 对，最开始非常不工作，短文本也不行。中间几年在语言建模上都没跑到很好。后来雷特线性加了遗忘衰减机制，发现扩大规模后效果不错了。它用的是输入无关的衰减，比如遗忘率0.99，每过一个词元就忘掉百分之一。

H: 后来输入无关的衰减被替换成了输入相关的？

G: 对，每个词元的衰减率由输入决定。模型觉得前面内容不要忘，就把衰减率设为一；觉得没用了，就设为零，前面状态完全忘掉。更灵活，能动态学习什么时候该遗忘、什么时候该记住。这是第一个大改进。

H: 第二个大改进是什么？

G: 增量规则。最早的线性注意力用黑边规则，就是把键和值的外积加到隐藏状态上，只有加法。增量规则多了减法——先用键取出旧值，用可学习系数决定新旧值的比例，做线性组合后更新。能有针对性地从记忆里删除东西。

H: 为什么线性注意力从一开始效果不好，大家还是相信它有前途？

G: 每次大家关心线性注意力，都是因为碰到了上下文窗口撞墙。2020年觉得8192就算长文本了，后来闪电注意力打破了这堵墙。再后来长文本推理又成大需求，人们又重新审视这套技术。核心就是效率——每当全局注意力效率变成瓶颈，大家就回来看线性注意力。

H: 那现在线性注意力是共识了吗？

G: 共识是纯线性注意力不工作，长文本有根本性缺陷。折中方案是混合注意力，有很多线性注意力层但也有全局注意力层，模型下限有保证。纯线性的循环状态数目恒定，上下文长了早晚存不下。混合注意力有全局注意力兜底，Kimi线性和千问3下一代在长文本测试上都没掉点。

H: 你参与Kimi线性工作，具体贡献是什么？

G: 张宇想完细粒度衰减率后，我帮他想了一个并行算法。之前有篇文章把门控增量网络的求逆减少了一次，我发现增量网络也可以，紧接着又推了适用于KDA的算法。张宇去实现，发现稳定性确实更好。这基本是我对这个工作唯一的贡献。

H: 从你的角度看，注意力机制到底应该怎么设计？

G: 主流就两条路：混合线性和稀疏注意力，都很有前途。还有些非主流的，比如Meta搞三次方注意力，平方复杂度还不够。改进注意力要么把全局注意力做得更好，要么做更高效的变种。这两种我觉得也可以结合。

H: 如果把模型架构比作大脑，混合专家模型和注意力分别代表什么？

G: 注意力相当于工作记忆，即时性处理新场景里的上下文。前馈网络像海马体，存储过去的知识和信息。前馈网络基本上是一个关联记忆网络，词元知识都存在里面。

H: 现在数据撞墙了，算法创新是不是变得更重要了？

G: 是的，要在有限数据里压缩更多智能。之前数据能堆的时候谈数据效率没用，大家只要加数据就行。现在有数据墙、算力墙，最终还是要回到算法本质。数据、算法、算力三驾马车缺一不可。

H: 你觉得变换器架构的天花板是什么？

G: 先把效率问题解决掉。现在处理长上下文还有局限，所以大家做上下文工程、检索增强。如果上下文问题解决了，检索增强都不需要了，直接放到上下文里做上下文内检索就行了。

H: 所以天花板就是看能不能把全局注意力干掉？

G: 这是第一点，因为它确实是阻止上下文窗口继续扩大的主要瓶颈。第二点可能是持续学习，现在变换器做不了持续学习。之后大家甚至想把预训练变成直接从强化学习开始，让模型从零开始学。

H: 从硬件演进角度，下一代算法会怎么走？

G: 硬件跟变换器协同演进，越来越优化矩阵乘法。张量核心、张量内存加速器都是为了矩阵乘法。所以设计算法必须有矩阵乘法，不然硬件效率跟不上。闪电注意力第四代在新硬件上会越来越快，矩阵乘法快到指数运算都变成瓶颈了。

H: 深度求索和Kimi哪个在硬件亲和上做得更好？

G: 深度求索，绝对。他们非常追求低精度运行，基础设施团队话语权很高。他们那个稀疏注意力的索引器用低精度算注意力分数，不需要指数运算，基本上就是大堆矩阵乘法，特别快。这些性质有可能被用到下一代架构里。

H: 你觉得中国算法创新跟硅谷整体是什么格局？

G: 架构这块国内肯定更强，因为卡少效率要求高。美国公司更注重优化器，投入比国内大。国内也在跟进，Kimi是最早吃螃蟹的。各有各的优势。

H: 你参与千问3下一代的工作吗？MiniMax呢？

G: 千问3基本是顾问角色，碰到问题我帮忙看一下，有学术讨论我会参与，跟训练的几个同学都挺熟。MiniMax没有参与。如果我参与了，他们应该不会用那个方案，我会觉得在开倒车。

H: 哈哈，你说话很直接。那如果年轻研究者想进入这个领域，你有什么建议？

G: 找个公司去实习。做架构必须要有算力，没有算力就没法做架构。这是最实在的建议。

H: 你读博过程中遇到过什么挫折吗？

G: 感觉都还挺顺的。可能因为读博前花了半年调研，对领域理解很深。深根这个领域来做，碰到什么问题大家都知道怎么解。

H: 你觉得最大的挑战是什么？

G: 你不知道你要做什么东西，不知道做什么是有用的，这才是最大的挑战。技术上的挑战都有办法搞定。

H: 所以核心是从历史中学习。你管这叫考古。

G: 对，我特别喜欢看最早的那些论文，写得都挺好的。不同人有不同的研究哲学，但我觉得一定要把领域里值得看的文章全部看一遍。

H: 好了，今天的节目就是这样。感谢松林带来这么硬核的分享。这里是商业访谈录，由语言及世界工作室出品。公众号是语言及世界，我们希望和你一起从这里探索新的世界。

G: 谢谢大家，再见。
